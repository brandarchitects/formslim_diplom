# Schriften (FS Joey)

Bitte die FS-Joey-Schriftdateien hier ablegen. Erwartete Dateinamen
(`.ttf` oder `.otf`):

- `FSJoey-Regular.ttf`
- `FSJoey-Bold.ttf`
- `FSJoey-Heavy.ttf`

Alternative Schreibweisen wie `FS Joey Regular.ttf`, `FSJoey_Bold.otf` usw.
werden ebenfalls erkannt.

Solange die Dateien fehlen, verwendet die App eine Ersatzschrift und zeigt
einen Hinweis an. Für den PDF-Export mit eingebetteten FS-Joey-Schriften
müssen die Dateien vorhanden sein.
